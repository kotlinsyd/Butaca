# Butaca

Butaca finds a working link for the Spanish movie or show you ask for and hands it to your app. It holds no files — the video goes straight to you.

**Get it here:** https://butaca.plavio.site

## What it does

- Spanish audio first — pick Spanish or Polish (Beta), and you only get links in that language
- Every link shows its quality and size
- Sort by size, cap the quality, limit the results — your settings travel inside the install link
- No key, no sign-up, no password

Italian is coming soon.

Butaca is still in its early stage — it will keep getting better over time.
